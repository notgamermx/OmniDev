# Roadmap

## Phase 1: Foundation

Complete the local Python/FastAPI/SQLite foundation, configuration, migrations, logging, exception handling, basic tests, and documentation.

## Phase 2: Core application architecture

Add lifecycle management, projects and workspaces, a service registry, events, background tasks, and application state.

Later phases can add independent OpenCode and LLM provider adapters, agents, terminal execution behind explicit permissions, and user interfaces. Those capabilities are intentionally outside Phase 1.
