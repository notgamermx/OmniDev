# Web workbench

The web interface shares the React source in `apps/desktop/renderer` with Tauri. Build with `npm --prefix apps/desktop/renderer run build`, start `omnidev serve`, and open `/app/`. For frontend development run `npm --prefix apps/desktop/renderer run dev`; Vite proxies `/api` to the local engine.
