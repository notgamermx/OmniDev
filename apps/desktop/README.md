# Tauri desktop

The desktop client uses Tauri 2 and the shared React workbench in `renderer/`. Install the platform prerequisites from https://v2.tauri.app/start/prerequisites/, run `npm ci` here and in `renderer`, then `npm run dev` or `npm run build`. Start the separately installed Python engine with `omnidev serve`. The Connection screen selects a local or remote engine. Linux release target: deb.
